## 変更内容

画像取込で毎回修正していた分類・支払経路を、取込元・元口座・取引先・収支の範囲付きルールとして明示保存し、次回から再利用できるようにします。一般設定と取込元の両方で許可され、一意なルール・原文根拠・確定日付・整合性・重複確認が揃う通常取引だけを自動反映します。

- 日付不明・年不明を当日で補わず、原文由来／利用者指定／未確定を区別。対象を選択した日付一括指定に確認プレビューを追加。
- チャージ・振替・カード引落・返金・取消・手数料を区別し、分類や支払経路に矛盾する候補を保留。
- ルール管理、自動反映の件数・方向別金額・適用ルール表示、実績訂正の差分確認を追加。再送・二重送信では確定済みの処理を繰り返しません。

## 検証

- 最終修正後の全RSpec：MySQL 8.0／PostgreSQL 16それぞれ362 examples、0 failures、既存pending 8件。
- 最終修正前の両DB×migration／schema構築：全4条件で各349 examples、0 failures、既存pending 8件。既存値保持、DDL途中失敗からの再開、migration再実行、FK・default・NULL制約を検証。最終修正ではDB構造の変更はありません。
